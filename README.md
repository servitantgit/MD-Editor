# MD-Editor

Редактор `.md` файлів для GitHub-репозиторію (single-file, працює прямо в браузері через Personal Access Token).

## Що нового

- **Показ зображень у прев'ю** — картинки підвантажуються через GitHub API (працює і з приватними репозиторіями), а не як прямі посилання.
- **Масштабування зображень** — наведіть курсор на картинку в прев'ю, потягніть за синій квадратик у правому нижньому куті. Розмір записується як `<img src="..." width="...">` прямо в markdown.
- **Drag & drop зображень** — перетягніть файл(и) зображень у вікно редактора (або скористайтесь кнопкою "завантажити" в тулбарі) — картинка завантажиться в `assets/` поруч із поточним файлом і вставиться в текст.
- **Drag & drop файлів між папками** — у дереві файлів зліва можна перетягнути будь-який файл (включно із зображеннями) у папку або в зону "перемістити в корінь". Усі markdown-файли репозиторію автоматично скануються, і посилання на переміщений файл переписуються на новий шлях.
- **Експорт активної сторінки в PDF** — кнопка "📄 PDF" у тулбарі редактора генерує PDF з поточного відкритого файлу (з підставленими зображеннями).

## Обмеження, про які варто знати

- Посилання/зображення зберігаються у форматі, "кореневому" для репозиторію (`/шлях/до/файлу`), — це і дозволяє коректно переносити файли між папками без ручного перерахунку відносних шляхів. Якщо у вже наявних файлах є посилання виду `../assets/img.png`, вони автоматично конвертуються в кореневі лише в момент, коли сам `.md`-файл переміщується.
- Автозаміна посилань при переміщенні шукає точний рядок `/старий/шлях` — екзотично написані вручну посилання (без провідного `/`, з URL-кодуванням пробілів тощо) вона не гарантовано підхопить.
- Функціонал перевірявся вручну на коректність коду (JS-синтаксис, структура HTML), але **не був протестований проти реального GitHub-репозиторію** в цьому середовищі (немає доступу до живого API з токеном) — варто прогнати базовий сценарій (відкрити файл → вставити картинку → змінити розмір → перемістити файл → зберегти → експортувати PDF) одразу після розгортання.
