What you get

Write & preview

  • Source / Live / Preview — editor only, split, or full preview
  • Markdown, HTML & code — JS/CSS too, dark syntax theme
  • Outline, minimap, backlinks — navigate a real knowledge base
  • Multi-tab — undo, cursor & scroll kept per file
  • Find / replace · PDF export · image upload

Save on your terms

  • GitHub OAuth — no manual tokens, 2FA stays on GitHub
  • Local drafts — IndexedDB while you type; survives reload
  • Save or Commit — push one file or stage many, when ready
  • 409 conflict recovery — reload or overwrite, never silent
  • History & diffs — per-file history with restore

Organize

  • File & folder CRUD — create, rename, move, delete
  • Auto link rewriting — moves do not break refs
  • Drag & drop — files, folders, images
  • Full-text search — whole repo, in the browser
  • Repo switcher · private repos · mobile-friendly layout

Why not something else?

Why not github.dev?

Code-first. No markdown live preview, no PDF export, no drafts, no link rewriting on move.

Why not Obsidian?

Desktop app with manual Git sync. Here: zero install, phone-friendly reading/quick edits, desktop for full work.

Why not StackEdit?

No multi-file commits, no conflict recovery, no file tree ops, no link rewriting.

Why not OneNote / Notion?

Proprietary format, lock-in, no git history. Here notes are plain files in your repo — Markdown or HTML — forever yours.

Questions

Is my code safe?

Server never stores your token. Token lives only in this tab's sessionStorage, destroyed on close.

Does it work with private repositories?

Yes. Same OAuth grants access to any repo you permit. Previews work on private repos too.

What if I lose connection?

Edits land in IndexedDB within 400 ms. Reconnect and pick keep-or-discard — nothing merges automatically.

Can I self-host it?

Yes — Cloudflare Pages free tier. Callback is Pages Functions. See README-CLOUDFLARE.md.

What about my OneNote / Obsidian collection?

Export to markdown, push to a GitHub repo, open it here — plain files with full git history.
